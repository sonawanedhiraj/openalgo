| 0.1.3 | 2026-08-03 | Rolling additive watch list, **default OFF** (deploy is a no-op). Strictly additive — the 09:16 seed picks are never dropped and `watch_size` never shrinks. **The entry gate, the level, the one-entry-per-symbol rule and the `max_trades` cap are all unchanged**; added symbols compete for the same slots first-come-first-served. Each addition emits a `watchlist_add` decision-log event (symbol / side / % change at add / rank / watch size), rendered in a new "Rolling watch-list" panel on `/logs`; the selection-outcome table gains a seed-vs-rolling `source` column, and `open15_trades` gains `watch_source ∈ {seed, rolling}`. | Issue #529. 2026-08-03 replay: the 09:16 gap ranking placed the day's four biggest movers at ranks #22/#106/#130/#134, and two of the three symbols actually selected never entered the intraday top-3. ⚠ **The same study could NOT show the added names pay** — 3 incremental trades, +₹162, 1 win of 3, on the only 4 usable days. Shipped as a MEASUREMENT (hence `watch_source`), not a validated edge; sample size is blocked on #528. |
| 0.1.2 | 2026-08-03 | Observability only — no signal, sizing or gate change. The running max cumvol/baseline ratio is now published while the window is open: `get_status()` gains `watch_stats` + `vol_needed`, a new `watch_stats` decision-log event covers **every** selected symbol at the exit job (entered ones included), and `/logs` fills its `max vol×` column from both. `no_entry` keeps precedence, so pre-#524 stored days and the CSV export parse unchanged. `max_vol_ratio` is `None` (rendered `—`) until a symbol's first in-window tick, so "no ticks" stays distinguishable from a 0.0 ratio. The `needed` threshold now reports the day config's `vol_mult` rather than the raw env default. | Issue #524. The value was already computed tick-by-tick and final at the entry cutoff; it was simply never published until the exit job, leaving the column blank all session and permanently blank for entered symbols. |
| 0.1.1 | 2026-07-31 | Trade-side option: `trade_side` = `both` (default, unchanged behavior) / `long_only` / `short_only`, editable on `/open15_vol_breakout/logs` and via `POST /api/config`, env default `OPEN15_TRADE_SIDE`.
